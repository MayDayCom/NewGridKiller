# NEW GridKiller

웹하드 그리드 프로그램의 알려진 실행·자동 시작·서비스 흔적을 확인하고, 항목별로 맞는 방식으로 정리하는 Windows 도구입니다.

## 최신 버전

**3.1.5** · Windows 10/11 64비트

실행 파일은 [Releases](https://github.com/MayDayCom/NewGridKiller/releases)에서 받을 수 있습니다.

## 주요 기능

- Grid Killer 2 v.2.1.4.o에서 가져온 프로그램 DB를 기준으로 검사합니다.
- 검사 중 현재 확인 중인 이름과 진행률을 표시합니다.
- 발견한 프로세스, 자동 시작 등록, 서비스, 관련 파일과 경로를 확인합니다.
- 검사만으로는 시스템을 변경하지 않습니다. 정리할 항목을 선택하고 확인한 뒤 처리합니다.
- 항목별 제거 방식은 DB의 정리 규칙에 따라 다르게 적용합니다.

## 사용 방법

1. Releases에서 `NewGridKiller.exe`를 내려받아 실행합니다.
2. Windows가 관리자 권한을 확인하면 허용합니다.
3. **검사 시작**을 누르고 결과와 경로를 확인합니다.
4. 정리할 항목을 선택한 뒤 원하는 작업을 실행합니다.

일반 항목은 일치하는 프로세스와 자동 시작 항목을 정리하고, 서비스 시작을 막은 뒤 확인된 실행 파일을 처리합니다. **서비스 삭제**는 Windows 서비스 등록만 따로 제거합니다. 작업 전 확인 창이 표시됩니다.

## HGridEngine 정리 규칙

HGrid는 일반 항목과 다른 전용 절차를 사용합니다. `HGRID_ENGINE` 서비스의 실행 파일이 `HGridEngine.exe`이고 상위 폴더 이름이 `HGrid`인지 확인한 뒤, 서비스를 중지하고 등록을 삭제합니다. 이어 같은 확인된 폴더 안의 `HGridEngine.exe`와 `HGrid.dll`만 삭제하며, 다른 파일이 남아 있으면 폴더는 보존합니다. 서비스가 이미 없는 경우에도 실행 중 프로세스 경로가 같은 규칙에 맞으면 정리할 수 있습니다.

웹하드 다운로더나 부모 프로그램은 제거하지 않습니다. 해당 프로그램이 HGrid를 다시 설치할 수 있습니다. HGrid 정리 기준은 [HGridEngine 서비스와 파일 수동 제거 사례](https://pcwindows.tistory.com/398)와 [FileStar 설치 분석](https://pcwindows.tistory.com/659)을 참고해 반영했습니다.

## 검사 기준

내장 DB에서 프로그램 이름, 프로세스 이름, 자동 시작 값, 서비스 이름과 항목별 정리 방식을 확인합니다. 새 규칙을 내려받거나 인터넷에서 프로그램 정보를 조회하지 않습니다.

## 버전 안내

3.1.5는 HGridEngine 규칙과 전용 정리 방식을 추가했습니다. AutoIt 기반 Grid Killer 2 v.2.1.4.o의 검사 DB를 바탕으로 새로 만든 C# WPF 버전이며, 원본의 임시 업데이트 파일 다운로드와 외부 웹 페이지 이동 기능은 포함하지 않았습니다.

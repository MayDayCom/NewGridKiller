# NEW GridKiller

웹하드 그리드 프로그램의 알려진 실행·자동 시작·서비스 흔적을 확인하고 정리하는 Windows 도구입니다.

## 최신 버전

**3.1.4** · Windows 10/11 64비트

실행 파일은 [Releases](https://github.com/MayDayCom/NewGridKiller/releases)에서 받을 수 있습니다.

## 주요 기능

- Grid Killer 2 v.2.1.4.o에서 가져온 프로그램 DB를 기준으로 검사합니다.
- 검사 중 현재 확인 중인 이름과 진행률을 표시합니다.
- 발견한 항목의 프로세스, 자동 시작 등록, 서비스, 실행 경로를 확인할 수 있습니다.
- 검사만으로는 시스템을 변경하지 않습니다. 정리할 항목을 선택하고 확인한 뒤 처리합니다.

## 사용 방법

1. Releases에서 `NewGridKiller.exe`를 내려받아 실행합니다.
2. Windows가 관리자 권한을 확인하면 허용합니다.
3. **검사 시작**을 누르고 결과를 확인합니다.
4. 정리할 항목을 선택한 뒤 원하는 작업을 실행합니다.

선택 항목 정리는 해당 프로세스를 종료하고 연결된 자동 시작 등록을 제거합니다. 서비스는 사용 안 함으로 바꾸며, 확인된 실행 파일도 삭제할 수 있습니다. **서비스 삭제**는 Windows 서비스 등록을 제거하는 별도 작업입니다. 두 작업 모두 실행 전에 확인 창이 표시됩니다.

## 검사 기준

프로그램 이름, 프로세스 이름, 자동 시작 값, 서비스 이름을 포함한 내장 DB로 확인합니다. 새 규칙을 내려받거나 인터넷에서 프로그램 정보를 조회하지 않습니다.

## 버전 안내

3.1.4는 AutoIt 기반 Grid Killer 2 v.2.1.4.o의 검사 DB를 바탕으로 새로 만든 C# WPF 버전입니다. 원본의 임시 업데이트 파일 다운로드와 외부 웹 페이지 이동 기능은 포함하지 않았습니다.
